Версия 0.2

Смена порядка игроков

Теперь в методе runGame после каждого сета изменяется игрок, который будет ходить первым.

В класс UnoGame было добавлено поле int currentDiller_, которое хранит номер игрока, который будет ходить первым в следующем сете. Значение этого поля может быть получено методом currentDiller(), а значение установлено методом setCurrentDiller(int) и увеличено методом stepCurrentDiller.

Утилиты для проведения экспериментов

В файле utils/stats.h описан наблюдатель, который собирает статистику проведения партий. Объект класса StatsObserver сохраняет победителя каждой игры и итоговое количество очков всех игроков на конец игры.

Полученные данные можно вывести в формате TSV для того, чтобы обработать самостоятельно. Класс StatsObserver может сделать простейшую обработку полученных таблиц: подсчет среднего и матрицы ковариации (проще: отклонения).

Для запуска серии игр можно использовать функцию runGames из файла utils/stats.h.

В файле main.cpp приведен пример использования класса StatsObserver и функции runGames.
